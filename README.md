# 📚 Estudo: tela de login 2

Segunda tela de login, só em HTML e CSS, feita entre fevereiro e março de 2023 para praticar layout responsivo com media queries.

**Demo:** https://samuellauro.github.io/estudo-tela-login-2/

## O que pratiquei

- Formulário estilizado com imagem de fundo.
- Media queries (`estilos/mediaquery.css`) para adaptar a tela a celulares e tablets.
